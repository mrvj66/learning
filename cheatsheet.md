## Команды Git (справочник)

### Настройка (один раз на компьютер)
| Команда | Что делает |
|---|---|
| `git config --global user.name "Имя"` | Задаёт имя автора коммитов |
| `git config --global user.email "почта"` | Задаёт почту автора (та же, что на GitHub) |
| `git config --global init.defaultBranch main` | Главная ветка будет называться main |
| `git config --global --list` | Показывает все настройки |

### Начало работы
| Команда | Что делает |
|---|---|
| `git init` | Включает Git в текущей папке (создаёт скрытую папку .git) |
| `ls -a` | Показывает все файлы, включая скрытые (например, .git) |

### Каждый день
| Команда | Что делает |
|---|---|
| `git status` | Показывает, что изменилось. Красный = не добавлено, зелёный = добавлено |
| `git diff` | Показывает, какие именно строки изменились (выход — q) |
| `git add файл` | Добавляет файл в следующий коммит («кладу в коробку») |
| `git add папка` | Добавляет все файлы из папки |
| `git commit -m "сообщение"` | Делает коммит — снимок с описанием («заклеиваю коробку») |
| `git log --oneline` | Показывает историю коммитов коротко, по одной строке |
| `git log` | Подробная история: автор, дата, сообщение (выход — q) |

### Как читать git log --oneline
`97c7884 (HEAD -> main) Добавил конспекты дней 1-3`
- `97c7884` — номер (хеш) коммита
- `HEAD` — где я сейчас
- `main` — название ветки
- остальное — сообщение коммита

### Порядок действий для коммита
1. Изменил файлы
2. `git status` — посмотрел, что изменилось
3. `git add ...` — выбрал файлы
4. `git status` — проверил, что выбрал правильно
5. `git commit -m "..."` — сохранил
6. `git log --oneline` — убедился, что коммит появился
7. `git log --stat` - Какие файлы менялись в каждом коммите:
8. `git show` - Что именно изменилось в конкретном коммите (подставь свой номер из git log --oneline):
