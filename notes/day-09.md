# День 9 — Типы данных и Printf

## Типы
- `%T` показывает тип: `fmt.Printf("%T\n", x)`
- `17` — int, `17.0` — float64: одна точка меняет тип
- Разные типы смешивать нельзя: `mismatched types int and float64`

## Преобразование типов
- `float64(a)` — значение a в виде float64
- `int(x)` — значение x в виде int, дробная часть ОТБРАСЫВАЕТСЯ: int(7.99) = 7
- Сама переменная не меняется, берётся копия значения
- Деньги: price * float64(quantity), потому что у денег есть копейки

## Printf — печать по шаблону
- Шаблон с «дырками», значения после него через запятую, по порядку
- Сколько дырок — столько значений
- `fmt.Printf("%d + %d = %d\n", a, b, a+b)`

| Глагол | Для чего |
|---|---|
| %d | целое |
| %f | дробное |
| %.2f | дробное, 2 знака |
| %s | строка |
| %t | bool |
| %v | любое |
| %T | тип |
| %% | сам знак процента |

## Printf vs Println
- Printf НЕ ставит перевод строки сам: нужен `\n`
- Printf не ставит пробелы между значениями
- Вычисления пишутся после шаблона, а не внутри кавычек

## Интересное
- float64 хранит дроби неточно: 249.90 * 3 = 749.6999999...
- В банках деньги хранят в копейках, целыми числами
