# День 6 — Первая программа на Go

## Главное своими словами
- Что такое go.mod и зачем `go mod init` создает паспорт проекта Go 
- Чем `go run` отличается от `go build` 1. компилирует и сразу запускает программу 2. Собирает файл программы в текущей папке 
- Почему программу запускают как `./go-hello`? потому что она не входит в PATH и ей надо указать путь 

## Разбор программы
- `package main` — это запускаемая программа 
- `import "fmt"` — это отдельный пакет из обычной библиотеки Go 
- `func main()` — это функция с нее начинается программа 
- `fmt.Println(...)` — из пакета fmt вызываем функцию Println, она печатает текст на экран и переводит строку

## Мой код
package main

import "fmt"

func main() {
	fmt.Println("Привет, меня зовут Влад!")
	fmt.Println("Моя цель научиться программировать и найти работу!")
	fmt.Println("Мое любимое занятие это проводить время так, как я хочу!")
}
