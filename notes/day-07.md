# День 7 — Повторение недели

## Пути
- `~` — домашняя папка (/Users/vladzotov). `~/projects` ≠ `~/learning/projects`
- Абсолютный путь: полный адрес от `~` или `/`, работает откуда угодно
- Относительный путь: от текущей папки, начинается с имени или `..`
- Из notes в projects: `cd ../projects`

## Git
- Порядок: `git status` → `git add` → `git status` → `git commit -m` → `git push`
- Untracked — новые файлы, для которых ни разу не делали `git add`
- `nothing added to commit` — коробка пуста: файл не изменился или не добавлен
- `git status -u` — показывает каждый неотслеживаемый файл, а не только папку
- `git restore файл` — вернуть файл к последнему коммиту

## SSH-ключи
- `id_ed25519.pub` — публичный, «замок», отдаём GitHub
- `id_ed25519` — приватный, «ключ», НИКОГДА и никому

## .gitignore
- Список файлов, которые Git не отслеживает
- Пути считаются от папки, где лежит .gitignore (от learning)
- Собранную программу не храним: её можно собрать заново через go build
- `echo "строка" >> файл` — дописать в конец (`>` перезапишет весь файл!)

## package
- `package main` — запускаемая программа
- Другой пакет (fmt, hello) — библиотека, его подключают через import

## Мини-проект: визитка
- Рамка — обычный текст из + - |, каждая строка — fmt.Println
- Ровная рамка = одинаковое число символов в каждой строке
