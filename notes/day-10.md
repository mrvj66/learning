# День 10 — Константы и ввод с клавиатуры

## Константы
- `const deliveryFee = 99.0` — значение нельзя изменить
- Через `const` и `=`, не через `:=`, значение указывается сразу
- Обычно пишут в начале файла, перед func main
- Зачем: защита от случайной правки, одно место для изменения,
  понятное имя вместо «магического числа»
- Вопрос: «может ли значение измениться во время работы?»
  Нет → константа (доставка, налог, название). Да → переменная (цена, имя)

## Ввод: fmt.Scan
- `var name string` — заранее пустая коробка (не :=, ведь значения ещё нет)
- `fmt.Print("Имя: ")` — вопрос без перевода строки
- `fmt.Scan(&name)` — ждёт ввода и кладёт ответ в name
- `&` — адрес коробки: Scan нужно знать, КУДА положить ответ
- Без & программа соберётся, но переменная останется пустой (тихая ошибка!)

## Особенности Scan
- Читает до пробела: «Влад Зотов» → «Влад»
- Сам превращает текст в тип переменной
- Буквы в int → переменная остаётся 0
- Дробные числа вводить через точку: 249.90

## Print, Println, Printf
- Print — как есть, без перевода строки
- Println — с переводом строки и пробелами
- Printf — по шаблону
