# День 8 — Переменные

## Переменная
- Коробка с наклейкой: имя (наклейка), тип (форма коробки), значение (содержимое)
- `var city string = "Москва"` — полная форма
- `year := 2026` — короткая, тип Go выводит сам, только внутри функций
- `:=` СОЗДАЁТ переменную, `=` МЕНЯЕТ значение существующей
- `score = score + 5` читается справа налево: посчитать и положить обратно

## Базовые типы
- string — текст, int — целое, float64 — дробное, bool — true/false
- Тип переменной не меняется
- Тип определяет, какие действия разрешены

## Арифметика
| Знак | Действие | 17 и 5 |
|---|---|---|
| + | сложение | 22 |
| - | вычитание | 12 |
| * | умножение | 85 |
| / | деление | 3 (int!) |
| % | остаток | 2 |

- int / int → дробная часть ОТБРАСЫВАЕТСЯ, а не округляется: 19 / 5 = 3, не 4
- float64: 17.0 / 5.0 = 3.4
- % работает только с целыми числами

## Println
- Принимает несколько значений через запятую, ставит между ними пробелы
- В кавычках — текст как есть, без кавычек — переменная или выражение
- `fmt.Println(a, "+", b, "=", a+b)` → 17 + 5 = 22

## Строгий Go
- `declared and not used` — создал переменную и не использовал
- `no new variables on left side of :=` — второй раз := для той же переменной
- `invalid operation: operator % not defined on ... float64` — % для дробных
