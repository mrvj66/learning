# День 11 — Условия

## if
- `if условие { ... }` — выполнить блок, только если условие верно
- Без скобок вокруг условия, `{` на той же строке
- Условие — вопрос с ответом да/нет, результат bool

## Сравнения
| Знак | Вопрос |
|---|---|
| == | равно? |
| != | не равно? |
| > < | больше? меньше? |
| >= <= | больше или равно? меньше или равно? |

- `=` КЛАДЁТ, `==` СРАВНИВАЕТ. В условии всегда ==
- Строки сравниваются так же: `op == "+"`
- Сравнивать можно только одинаковые типы: int с числом, string со строкой

## else, else if
- `else` — иначе, выполнится ровно один блок из двух
- `else if` — следующая проверка
- Проверки идут сверху вниз, срабатывает ПЕРВОЕ верное, порядок важен
- Внутри if можно писать другой if (вложенное условие)
- У одного if может быть только один else

## Логические операторы
- `&&` — И: верны оба
- `||` — ИЛИ: верно хотя бы одно
- `!` — НЕ

## Приёмы
- Деление int на 0 — panic (аварийная остановка). Проверяй делитель заранее
- После цепочки if можно проверить, чем она кончилась: `if name == ""`
- Сначала отсеять все ошибки, в последнем else — основная работа

## Где я ошибся
- `if a + b` — это вычисление, а не вопрос. Правильно `if op == "+"`
- op был int, а знак «+» — это string
- `if b = 0` вместо `if b == 0`
- `%` с float64 не работает — только с целыми
- В шаблоне `+`, а считается `*` — подпись должна совпадать с вычислением
